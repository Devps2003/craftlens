# ADR 0004 — License

## Status

Undecided. Blocked on the repository owner.

## Decision

No LICENSE file is shipped. `package.json` says `UNLICENSED`, which means "not a grant of rights," not a public-domain dedication. Do not publish to Open VSX until the owner chooses a license and a publisher id.

## Consequences

The tree can be built and reviewed locally. It is not ready for a public release.
